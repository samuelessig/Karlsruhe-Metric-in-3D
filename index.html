WebGL Demo

Voronoi Diagrams in 3D

Karlsruhe Metric


This demo is the WebGL build of the Unity project. It runs directly in your web browser, but it has some limitations compared to running the project in the Unity Editor or a Windows build.
Apart from the performance, the main limitation is that shaders in the WebGL build cannot use dynamic loops and variable size arrays. The maximum number of points must be known at compile time. This build is limited to 64 points, which is enough to show-case the shaders and it still runs smoothly in the web browser. Some of the example scenes require more points and will not load correctly though.

If you want to run the demo with more points or explore the source code, please check out the GitHub repository: https://github.com/samuelessig/Karlsruhe-Metric-in-3D
You can download a Windows build in the "Releases" section of the GitHub repository, or you can run load the project in the Unity Editor.
